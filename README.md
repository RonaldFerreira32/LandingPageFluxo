# Fluxo

Landing page de alta conversão para o **Fluxo**, uma ferramenta SaaS de gestão de projetos e tarefas para equipes remotas.

## Demonstração

[Acessar o site publicado](https://fluxo-equipes-remotas.icypaste1.chatgpt.site)

## Recursos

- Header fixo com navegação responsiva
- Hero com mockup construído em HTML e CSS
- Seções de recursos, prova social, preços e FAQ
- Menu mobile e FAQ acessíveis
- Animações suaves com suporte a movimento reduzido
- Layout responsivo para desktop, tablet e mobile

## Tecnologias

HTML5, CSS3, JavaScript puro e SVGs inline.

## Executar localmente

Abra `index.html` no navegador ou sirva esta pasta com qualquer servidor HTTP estático.
